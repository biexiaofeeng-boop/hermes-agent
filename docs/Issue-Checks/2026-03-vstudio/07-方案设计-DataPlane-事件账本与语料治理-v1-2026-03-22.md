# 方案设计：Data Plane 事件账本与语料治理（v1）

- 日期：2026-03-22
- 状态：READY

## 1) 数据平面最小目录

```text
data-plane/
  events/
    <node_id>/YYYY-MM-DD.jsonl
  materialized/
    ledger.sqlite
  corpus/
    training_corpus_YYYY.jsonl
  snapshots/
    YYYYMMDD-HHMM/
```

## 2) 事件账本约束

1. append-only，不允许原地改写。
2. 每条事件必须含 `event_id` 与 `node_id`。
3. 物化库可删可重建，jsonl 为事实源。

## 3) 语料抽取约束

1. 抽取格式：`instruction/input/output/timestamp/source/quality`。
2. 主语料门槛：`quality.evidence=true` 或 `quality.human_approved=true`。
3. 对话与执行语料分桶：`dialogue/execution/strategy/research`。

## 4) 与现网兼容策略

1. 中间层可独立关闭。
2. 不读取中间层时，系统保持旧行为。
3. 不将 Data Plane 写回 Cherry/chimera 主数据库。

## 5) 节点扩容策略

1. 节点新增仅需新增 `node_id` 与写入目录。
2. 同步采用“事件复制 + 幂等导入”。
3. 不做跨节点实时强一致，优先最终一致与可回放。

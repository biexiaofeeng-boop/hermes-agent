# 发布与回滚 SOP：S8-vstudio（v1）

- 日期：2026-03-22
- 状态：READY

## 发布前检查

1. 中间层开关默认关闭。
2. Cherry 与 chimera-core 主链冒烟通过。
3. Data Plane 写入路径权限与磁盘配额正常。
4. 影子模式回测通过（至少 1 天）。

## 发布步骤

1. 启用 `shadow_write=true`。
2. 观察错误率、时延、日志增长速率。
3. 启用 `read_only_query=true`（仍不驱动执行）。
4. 小流量白名单启用执行联动。

## 回滚条件

1. 主链响应失败率上升。
2. 对话明显卡顿。
3. 事件写入导致资源异常（磁盘/锁竞争）。
4. 链路回放无法对齐关键任务。

## 回滚动作

1. 关闭新开关：`shadow_write=false`, `read_only_query=false`, `bridge_link=false`。
2. 保留事件文件用于复盘，不删除主数据。
3. 回退到上一稳定发布版本。
4. 复盘后再进下一轮小流量。

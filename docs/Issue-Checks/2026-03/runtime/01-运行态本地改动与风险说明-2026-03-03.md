## 3) 风险评级（仅针对非运行产物）

### P0（立即处理）
1. 明文密钥泄漏风险
   - 文件：`nanobot/skills/web-search/SKILL.md`、`nanobot/skills/web-search/tavily_run.py`
   - 问题：硬编码 Tavily API Key
   - 风险：密钥外泄、滥用、账单风险、后续审计困难
   - 建议：
     - 立即轮换该 key
     - 改为环境变量读取（如 `TAVILY_API_KEY`）
     - 禁止在文档和示例脚本中出现真实 key

### P1（高优先）
2. 指令歧义保护被弱化
   - 文件：`nanobot/agent/loop.py`
   - 问题：通过关键词直接绕过歧义拦截
   - 风险：误触发执行、行为不可预测、授权链路边界被削弱
   - 建议：
     - 将“绕过条件”收敛为明确命令前缀（如仅 `task:`/`execute:` 且需结构化参数）
     - 对中文口语词（如“宝子们”“直接执行”）移除直通逻辑
     - 增加对应单元测试覆盖绕过条件

3. `tavily_run.py` 存在语法错误
   - 文件：`nanobot/skills/web-search/tavily_run.py`
   - 问题：多行 f-string 字符串未闭合，`python -m py_compile` 报 `SyntaxError: EOL while scanning string literal`
   - 风险：脚本无法执行，易在运行期误判为“网络/接口异常”
   - 建议：
     - 先修复字符串拼接语法
     - 将该脚本纳入最小 lint/语法检查（至少 py_compile）

### P2（中优先）
3. `.venv` 软链指向与仓库默认值不一致
   - 文件：`.venv`
   - 问题：部署目录本地化软链改动会触发发布脚本 tracked change

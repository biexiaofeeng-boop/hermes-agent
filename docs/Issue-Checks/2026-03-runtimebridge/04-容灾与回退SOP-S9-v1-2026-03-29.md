# 容灾与回退 SOP：S9（v1）

- 日期：2026-03-29
- 状态：READY

## 发布前约束

1. `runtime_lane.enabled` 默认关闭。
2. `failopen=true` 默认开启。
3. fast lane 冒烟测试必须先通过。
4. `ironelf` health 检查必须有明确超时。

## 运行时回退规则

1. `health` 失败：
- 直接 stay local，不再尝试 runtime lane。

2. `submit` 失败：
- 记录 bridge failure；
- 走本地执行或返回 `execution_state=fallback_local` / `blocked`。

3. `stream` 中断：
- 标记 `runtime_degraded`；
- 汇总已知 evidence；
- 由 `chimera-core` 输出简洁终态说明。

4. `receipt` 缺失：
- 禁止输出成功宣称；
- 只允许输出“runtime 失联 / 证据不足 / 需要重试”。

## 回滚动作

1. 关闭 `runtime_lane.enabled`
2. 保留 trace 与错误记录用于复盘
3. 恢复现有 fast lane-only 路径
4. 不要求 `ironelf` 先恢复，`chimera-core` 应可单独继续运行

# Mock Bridge 联调样例：S9（v1）

- 日期：2026-03-29
- 状态：READY

## 目标

1. 让 `chimera-core` 在 Rust 侧未完成时仍可独立开发桥接逻辑。
2. 让 `ironelf` 在 Python 侧未完成时也能按固定 contract 校验返回结构。
3. 把“无依赖回测”建立在固定请求、固定事件、固定回执样例上。

## 样例 1：健康检查

### Request

```http
GET /health
```

### Success Response

```json
{
  "schema_version": "v1",
  "ok": true,
  "status": "ready",
  "mode": "ok"
}
```

### Degraded Response

```json
{
  "schema_version": "v1",
  "ok": false,
  "status": "degraded",
  "mode": "health_down"
}
```

## 建议 mock 模式

1. `ok`：正常受理、正常事件、正常 receipt
2. `health_down`：health 失败，验证 fast lane-only 回退
3. `submit_fail`：派发失败，验证 fail-open
4. `blocked`：准入拒绝，验证 blocked 收口
5. `event_drop`：事件流中断，验证 degraded 总结
6. `receipt_missing`：无终态回执，验证 success-claim guard

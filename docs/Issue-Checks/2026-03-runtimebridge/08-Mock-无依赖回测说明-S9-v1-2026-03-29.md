# Mock 无依赖回测说明：S9（v1）

- 日期：2026-03-29
- 状态：READY

## 目标

使用本地 Python 标准库脚本模拟 `ironelf` bridge，让 `chimera-core` 在 Rust 侧尚未完成时也能回测：

1. runtime lane 路由
2. bridge client
3. fail-open 回退
4. success-claim guard
5. `FinalReport` 收口

## Mock 脚本

- `deploy/it/mock_ironelf_bridge.py`

## 启动命令

```bash
cd /Users/sourcefire/X-lab/chimera-core
python3 deploy/it/mock_ironelf_bridge.py --host 127.0.0.1 --port 8787 --mode ok
```

## 可切换模式

```bash
python3 deploy/it/mock_ironelf_bridge.py --mode health_down
python3 deploy/it/mock_ironelf_bridge.py --mode submit_fail
python3 deploy/it/mock_ironelf_bridge.py --mode blocked
python3 deploy/it/mock_ironelf_bridge.py --mode event_drop
python3 deploy/it/mock_ironelf_bridge.py --mode receipt_missing
```

## Python 线建议回测点

1. `mode=ok`
- 验证 submit / events / receipt / final report

2. `mode=health_down`
- 验证启动期直接 stay local

3. `mode=submit_fail`
- 验证派发失败后自动 fallback

4. `mode=event_drop`
- 验证 runtime degraded 但主线程仍能收口

5. `mode=receipt_missing`
- 验证不能宣称“已执行成功”

## Rust 线建议使用方式

1. 对照 `07-Mock-Bridge-联调样例-S9-v1-2026-03-29.md` 保持返回结构兼容。
2. 先保证字段兼容，再逐步替换 mock 行为。
3. 当 `ironelf` 真 bridge 可用后，保持相同 contract 让 `chimera-core` 无感切换。

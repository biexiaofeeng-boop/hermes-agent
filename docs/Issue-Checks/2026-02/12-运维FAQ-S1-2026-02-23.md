# S1 运维 FAQ（能力治理与任务协同）

- 日期：2026-02-23

---

## Q1：为什么 capability 列表是空的？

**现象**
- `capability list` 返回空。

**原因**
- 首次部署后 `registry/state` 是空壳，尚未执行同步。

**处理**
```bash
nanobot capability sync --from toolchain --from skills
nanobot capability check
nanobot capability list
```

---

## Q2：为什么普通任务也频繁弹授权？

**优先检查**
```bash
nanobot status
nanobot auth rules --status active
```

**判断逻辑**
- `execPolicy.mode=strict`：几乎所有 exec 都要授权。
- `execPolicy.mode=guardrail`：仅红线命令触发授权。

**建议**
- 主节点保持 `guardrail`。
- 长任务使用 `mission-grant`，避免重复授权。

---

## Q3：任务为什么一直 blocked（missing capabilities）？

**现象**
- `taskops feasibility` 显示 `Allowed=✗`，reason 包含 `missing capabilities`。

**处理**
```bash
nanobot capability list
nanobot capability check --id <capability-id>
```

若能力确实不存在：
1. 先在 toolchain/skills 增加能力来源。
2. 再 `capability sync`。

---

## Q4：明明装了 codex/claude，为什么没有被路由？

**检查顺序**
```bash
nanobot toolchain check --tool codex
nanobot toolchain check --tool claude-code
nanobot capability check --id executor:codex
nanobot capability check --id executor:claude
```

**常见原因**
- CLI 不在 PATH。
- 必要 env 未配置（如 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`）。
- `enabled=false`。

---

## Q5：web_search 为什么提示缺 key？

**原因**
- 运行时 `web_search` 使用 `BRAVE_API_KEY`。

**处理**
```bash
export BRAVE_API_KEY="<your-key>"
nanobot agent -m "请使用 web_search 搜索 'test query'"
```

---

## Q6：1Password 已安装，但任务仍不可用？

**原因**
- 默认 toolchain 未登记 1Password，需要先纳管。

**处理路径**
1. 在 `chimera-bridge/toolchain/registry.json` 新增 `1password-cli`。
2. `nanobot toolchain check --tool 1password-cli`。
3. `nanobot capability sync --from toolchain`。
4. `nanobot capability check --id service:1password-cli`。

---

## Q7：human 任务不通知 Telegram？

**检查**

```bash
nanobot status
nanobot taskops board
```

确保：
- `taskops.enabled=true`
- `taskops.humanNotify.enabled=true`
- `taskops.humanNotify.channel/to` 已配置
- Telegram channel 本身可用

---

## Q8：如何快速定位“卡点在能力还是在任务”？

1. 先跑 `nanobot capability status`（能力层）。
2. 再跑 `nanobot taskops feasibility`（任务层）。
3. 最后看 `nanobot auth list --status pending`（授权层）。

建议形成固定排查顺序：**能力 -> 任务 -> 授权 -> 通道**。

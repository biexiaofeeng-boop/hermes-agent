# 日周检查表：S2 运营稳态

## 每日检查（07:00 / 13:00 / 22:00）

推荐一键命令（覆盖日检）：
- bash deploy/chimera_ops_check.sh daily --profile prod

07:00 启动检查
1. bash deploy/chimera_profile.sh status
2. bash deploy/chimera_profile.sh health
3. bash deploy/chimera_watchdog.sh status --profile $(bash deploy/chimera_profile.sh current)
4. python3 -m nanobot.cli.commands taskops list --status blocked
5. python3 -m nanobot.cli.commands capability status

13:00 巡航检查
1. python3 -m nanobot.cli.commands auth list --status pending --limit 20
2. python3 -m nanobot.cli.commands taskops list --status in_progress
3. python3 -m nanobot.cli.commands cron list --all

22:00 收口检查
1. python3 -m nanobot.cli.commands taskops board
2. python3 -m nanobot.cli.commands taskops list --status failed
3. python3 -m nanobot.cli.commands auth list --status pending --limit 20

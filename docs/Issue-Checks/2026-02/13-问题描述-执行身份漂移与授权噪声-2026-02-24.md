# 问题描述：执行身份漂移与授权噪声

- 日期: 2026-02-24
- 面向对象: chimera-core-codex
- 问题等级: P0（执行稳定性）/ P1（授权体验）

## 一、背景与现象

本轮联调完成后，系统能力已经较完整（TaskOps + Capability + AuthGate + Dispatcher），但生产使用出现两类核心问题：

1. **执行体身份漂移**：对话中经常退化成“陪聊体/叙事体”，而不是稳定“执行体”。
2. **授权噪声与失败感知**：用户体感“反复授权”“偶发 not found”，影响连续执行。

这两个问题会叠加：当执行体漂移时，工具调用率下降；当授权链路噪声增加时，执行连续性进一步下降。

## 三、根因归纳

1. **身份模型层面**：核心提示缺少“执行优先级契约”，人格叙事文档占比过高。  
2. **授权语义层面**：`session` scope 实际是“session + paramsHash”，与用户直觉不一致。  
3. **观测层面**：`approve not found` 缺少结构化审计与友好回显，排障效率低。  
4. **上下文治理层面**：历史消息缺少压缩与层级化，长会话降低执行一致性。

## 四、影响评估

- 对生产执行的影响：P0（任务链路可能被中断/降速）。
- 对用户体验的影响：P1（“明明授权了还失败”的心理挫败明显）。
- 对后续扩展（多子代理调度）的影响：P0（控制层稳定性不足会放大复杂系统噪声）。

## 五、本轮迭代目标边界

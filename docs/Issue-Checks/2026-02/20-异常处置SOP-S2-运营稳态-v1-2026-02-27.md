# 异常处置 SOP：S2 运营稳态

## S0 统一入口

1. cd /Users/sourcefire/X-lab/chimera-core
2. bash deploy/chimera_profile.sh status
3. bash deploy/chimera_profile.sh health
4. bash deploy/chimera_watchdog.sh status --profile $(bash deploy/chimera_profile.sh current)
5. 演练脚本入口：bash deploy/chimera_ops_sop_drill.sh <s1|s2|s3|s4|s5|all> --profile prod
6. 先确认仓位边界：`chimera-core` 只跑 `test`，`chimera-core-prod` 只跑 `prod`。

## S1 授权风暴 / 授权失败

诊断：
- python3 -m nanobot.cli.commands auth list --status pending --limit 50
- python3 -m nanobot.cli.commands auth list --status approved --limit 50
- python3 -m nanobot.cli.commands auth rules --status active --limit 50

处置：
1. 关键链路使用 session 或 ttl scope。
2. 提升 approvalTtlS（建议 7200）。
3. 高风险工具保持最小集（exec）。
4. 保持 resume.enabled=true。

## S2 心跳无效

诊断：
- 检查 HEARTBEAT.md 是否为空或只有标题。
- python3 -m nanobot.cli.commands agent --session heartbeat:manual --message "Read HEARTBEAT.md and report health."

处置：
1. 修正 HEARTBEAT.md 为可执行清单。
2. 重启 gateway：bash deploy/chimera_profile.sh restart

## S3 TaskOps 停摆

诊断：
- python3 -m nanobot.cli.commands taskops list --status todo
- python3 -m nanobot.cli.commands taskops list --status in_progress
- python3 -m nanobot.cli.commands taskops feasibility --limit 200

处置：
1. 补 capability/toolchain 缺口。
2. 将僵尸任务改 blocked 并写原因。
3. 临时下调 maxBotTasksPerTick 为 1。

## S4 服务不可用

处置：
1. bash deploy/chimera_watchdog.sh status --profile $(bash deploy/chimera_profile.sh current)
2. bash deploy/chimera_profile.sh restart
3. bash deploy/chimera_profile.sh health

## S5 上下文偏航

诊断与修复：
- python3 -m nanobot.cli.commands context status --session cli:lobby
- python3 -m nanobot.cli.commands context projects
- python3 -m nanobot.cli.commands context switch arb --session cli:lobby

# 配置模板：S2 运营稳态

- 适用目录: /Users/sourcefire/X-lab/chimera-core

## 0) 环境边界（强约束）

- 开发仓 `/Users/sourcefire/X-lab/chimera-core` 仅允许运行 `profile=test`（默认端口 28790）。
- 生产仓 `/Users/sourcefire/X-lab/chimera-core-prod` 仅允许运行 `profile=prod`（默认端口 18790）。
- 禁止“双仓同时运行同一 profile”（尤其是 `prod`），否则会出现 watchdog 误判、PID 漂移与 Telegram polling 冲突。

## 2) 配置落地命令

1. 切到目录：
   cd /Users/sourcefire/X-lab/chimera-core
2. 查看当前 profile：
   bash deploy/chimera_profile.sh current
3. 应用稳态模板（推荐）：
   TG_CHAT_ID=<YOUR_CHAT_ID> bash deploy/chimera_ops_apply_steady_config.sh --profile prod --chat-id <YOUR_CHAT_ID> --approver <YOUR_CHAT_ID>
4. 重启并健康检查：
   bash deploy/chimera_profile.sh restart
   bash deploy/chimera_profile.sh health

## 3) 运营 cron 种子任务

- 早晨预热（07:00）
  python3 -m nanobot.cli.commands cron add --name ops-morning-warmup --cron "0 7 * * *" --message "执行晨检并输出今日重点"
- 晚间收口（22:00）
  python3 -m nanobot.cli.commands cron add --name ops-evening-close --cron "0 22 * * *" --message "执行晚间收口并更新任务池"
- 周复盘（周一 09:00）
  python3 -m nanobot.cli.commands cron add --name ops-weekly-review --cron "0 9 * * 1" --message "执行周复盘并给出优化建议"
- 查看任务
  python3 -m nanobot.cli.commands cron list --all
- 一键种子（幂等，推荐）
  bash deploy/chimera_ops_seed_cron.sh --profile prod

## 4) HEARTBEAT.md 最小模板

建议放入以下内容：
- 检查 TaskOps blocked/failed 是否新增
- 检查 pending 授权是否堆积
- 检查 watchdog 是否健康
- 无异常则回复 HEARTBEAT_OK
- 一键写入（推荐）：
  bash deploy/chimera_ops_write_heartbeat.sh --profile prod

## 5) Lobby 会话约定（S2-4）

- CLI 默认会话：`cli:lobby`
- 显式回主空间：`/project clear` 或 `/lobby`
- 建议日检附加命令：
  - `python3 -m nanobot.cli.commands agent --session cli:lobby --message '/project'`

## 场景 1：File & Shell（文件与命令）

### 目标

在指定目录执行命令并写回结果文件（最小可用自动化闭环）。

### 前置

- `AuthGate` 已启用。
- 目录可写：`/Users/sourcefire/X-lab/chimera-core/.runtime/reports/`。

### 执行

```bash
nanobot agent -m "请使用 exec 在 /Users/sourcefire/X-lab/chimera-core 执行 'ls -la'，并用 write_file 把摘要写入 /Users/sourcefire/X-lab/chimera-core/.runtime/reports/fs-shell-smoke.txt（含时间戳与关键文件列表）"
```

### 预期

- 生成文件：`/Users/sourcefire/X-lab/chimera-core/.runtime/reports/fs-shell-smoke.txt`。
- 若策略为 `guardrail` 且命令非红线，通常无需授权。

### 异常处理

- 若返回 `AUTH_REQUIRED`：执行 `nanobot auth list` + `nanobot auth approve <id>`。

## 场景 2：数据采集并归类到指定位置

### 目标

让 bot 任务自动采集并把产物落盘到固定目录。

### 前置

- `taskops.enabled=true`。
- 网关已运行（dispatcher 才会自动执行）。

### 执行

```bash
nanobot taskops add --title "收集本周模型新闻并归档" --owner-type bot --project ai-intel --priority 2 --difficulty 2 --description "采集近7天模型资讯，按 模型/工具/平台 三级归类，写入 /Users/sourcefire/X-lab/chimera-core/.runtime/reports/weekly/" --acceptance "至少10条结构化记录 + 1份 markdown 摘要"

nanobot taskops feasibility --limit 200
nanobot taskops board
```

### 预期

- 任务进入 `in_progress` 后最终回写 `done/blocked/failed`。
- 看板更新：`/Users/sourcefire/X-lab/chimera-core/chimera-bridge/boards/YYYY-MM-DD.md`。

### 异常处理

- 若长时间 `todo`：检查 gateway 是否运行、`taskops.enabled` 是否开启。

## 场景 3：Web 访问（1Password + websearch + webfetch）

### 目标

同时具备账号凭证读取 + 网页检索 + 网页抓取三段能力。

### 前置

- `BRAVE_API_KEY` 已配置（运行时 web_search 需要）。
- `op` 已安装并可登录。

### 执行

```bash
# 1) 凭证准备（示例）
export OP_SERVICE_ACCOUNT_TOKEN="<your-token>"
export BRAVE_API_KEY="<your-brave-key>"

# 2) 检查 1Password 能力
nanobot toolchain check --tool 1password-cli

# 3) 执行检索 + 抓取
nanobot agent -m "请使用 web_search 检索 'open-source agent orchestration 2026'，再用 web_fetch 抓取前2个结果并输出中文摘要（包含来源链接）"
```

### 预期

- 输出包含搜索结果列表与抓取摘要。
- 抓取结果中包含 `url/finalUrl/status/extractor/text`。

### 异常处理

- `Error: BRAVE_API_KEY not configured`：补齐 `BRAVE_API_KEY`。
- 需账号访问的站点：先在 shell 中通过 `op read` 取 token，再交给任务/命令使用。

## 场景 4：Codex/Claude 协作完善项目

### 目标

按任务难度把任务路由给 `executor:codex` 或 `executor:claude`，失败再回退。

### 前置

- `codex` / `claude` CLI 可执行。
- capability 已 `sync + check`。

### 执行

```bash
nanobot taskops add --title "重构 taskops 可观测性输出" --owner-type bot --project platform --priority 1 --difficulty 4 --description "优化任务事件日志结构并补充失败诊断字段" --acceptance "输出变更说明 + 回归检查项" --required-capabilities executor:codex --preferred-executor executor:codex --fallback-executors executor:claude,local-tools

nanobot taskops feasibility --limit 200
nanobot taskops board
```

### 预期

- `feasibility` 显示 `Allowed=✓` 且 executor 为首选或回退执行器。
- 执行后 `tasks.json` 可见 `selectedExecutor` 回写。

### 异常处理

- `executor:*` blocked：执行 `nanobot capability check --id executor:codex`（或 claude）定位缺失项。

## 场景 5：内容创作与 IP 运营（人机协同）

### 目标

bot 起草内容，human 审核发布，形成协同流水线。

### 前置

- `taskops.humanNotify.enabled=true`，并配置 `channel/to`。

### 执行

```bash
# A. bot 起草任务
nanobot taskops add --title "起草本周 AI 观察短文" --owner-type bot --project ip-ops --priority 2 --difficulty 2 --description "输出 800~1200 字中文稿，含3个可传播观点与配图建议" --acceptance "产出初稿 + 标题备选3个"

# B. human 审核任务（依赖 A）
nanobot taskops add --title "审核并发布 AI 观察短文" --owner-type human --owner-id captain --project ip-ops --priority 1 --difficulty 2 --depends-on <上一步任务ID> --description "审稿、修订、发布到目标渠道" --acceptance "发布并回填链接"
```

### 预期

- bot 任务完成后 human 任务进入可通知状态。
- notifier 向目标 chat 推送协同提醒。

### 异常处理

- 没收到通知：检查 `taskops.humanNotify.*` 与通道配置（如 Telegram token/chat）。

## 场景 6：指定关键词领域情报（HuggingFace + GitHub）

### 目标

按关键词自动采集模型/项目并产出周报。

### 前置

- `gh` 已登录，`GH_TOKEN` 可用。
- Python 环境可执行 HuggingFace watcher。

### 执行

```bash
cd /Users/sourcefire/X-lab/chimera-core

# 1) HuggingFace 数据抓取
python3 chimera-bridge/tools/data_miners/hf_watcher.py

# 2) GitHub 项目抓取（示例关键词）
mkdir -p .runtime/reports/ai-intel
gh search repos "topic:llm pushed:>=2026-02-16 stars:>100" --limit 30 --json name,url,description,stargazersCount,updatedAt > .runtime/reports/ai-intel/github_llm_weekly.json

# 3) 汇总成可读报告
nanobot agent -m "请读取 reports/hf_scan_*.json 与 .runtime/reports/ai-intel/github_llm_weekly.json，生成中文周报 markdown 到 /Users/sourcefire/X-lab/chimera-core/.runtime/reports/ai-intel/weekly_report.md，结构含：趋势、重点项目、风险、行动建议"
```

### 预期

- 产出：
  - `reports/hf_scan_YYYYMMDD.json`
  - `/Users/sourcefire/X-lab/chimera-core/.runtime/reports/ai-intel/github_llm_weekly.json`
  - `/Users/sourcefire/X-lab/chimera-core/.runtime/reports/ai-intel/weekly_report.md`

### 异常处理

- `gh search` 失败：先执行 `gh auth status`。
- watcher 失败：检查 `chimera-bridge/tools/data_miners/requirements.txt` 依赖。

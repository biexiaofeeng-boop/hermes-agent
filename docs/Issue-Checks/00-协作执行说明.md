# Phase1 协作执行说明（Codex 多线程）

## 目标
将 `bridge-taskops-phase1` 的实施与验收标准化，支持多个 `~/X-lab/` Codex 线程并行执行。

## 推荐分支策略
- 基线（已验证状态）: `codex/baseline-phase-ab-p1-20260219`
- 迭代分支（本轮开发）: `codex/bridge-taskops-phase1`
- 子任务分支（每线程）: `codex/bridge-taskops-phase1-<task-id>`

## 执行规则
1. 每个线程只认领一个任务卡（见 `01-Phase1-Issue-Backlog.md`）。
2. 先改代码，再更新任务卡状态（`TODO -> DOING -> CHECK -> DONE`）。
3. 每次提交必须附带：
   - 改动文件列表
   - 验证命令
   - 验证结果摘要
4. 不直接改其他线程负责的任务卡内容（只改自己任务块）。

## 合并规则
1. 子任务分支通过本地检查后，合并到 `codex/bridge-taskops-phase1`。
2. `codex/bridge-taskops-phase1` 完成全部验收后，再合并到主线。

## 目录说明
- `01-Phase1-Issue-Backlog.md`: 任务池（Issue 卡）
- `02-Checks-验收清单.md`: 统一验收与命令
- `03-线程交接模板.md`: 线程交接格式

## 约定
- 当前目录已统一为 `Issue-Checks`。
- 本轮以 `chimera-core` 为唯一工作树，避免影响线上运行中的 `nanobot`。
